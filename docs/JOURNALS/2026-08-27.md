### Security design (two coarse levels)
- **Level 1 — node↔node**: one shared **federation token** on every node;
  guards all federation endpoints (work-items, outbox, catalog, health) with a
  single middleware. Delegation only between configured peers.
- **Level 2 — systems using the node**: per-system **client tokens**
  (`api.clients`), individually revocable; guards `submit`/`status`. Default =
  access to all starting agents unless a token lists `agents`. Task results are
  scoped to the owning `client_id`.
- Costs: validators in each client token; optional revocation.
- **Contract** written as `docs/CONTRACTS/LEG-017-security.md`.

- Federation symmetric; peer allowlist via `federation.peers`.
- Coarse auth middleware in legio; granular auth = consumer application's layer.
