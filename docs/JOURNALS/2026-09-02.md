## Decisions taken

- **No lease, no retry, no re-queue in the dispatch**, anywhere (code + specs +
  design). An item is popped once and routed; a raised step is surfaced as an
  `error` result, never re-run. At-least-once execution and its reaper/DLQ
  machinery are removed (invented, unapproved).
- **TaskManager `next_run_at` as a submit-scheduling field is kept** (rule 8,
  approved) — it gates *when* a task runs, it is not a dispatch lease.
- **`recoverable`/`RecoverableError`/`UnrecoverableError` remain** as the
  approved LEG-016 typed error taxonomy (used by pattern loader/sequences);
  only the retry-feeding `retriable` surface and flags were removed.
- Rasante numbering R-7..R-10 are kept as-is (they mirror the GitHub issue
  labels R-0..R-10); only the R-6 label/issues were removed.
