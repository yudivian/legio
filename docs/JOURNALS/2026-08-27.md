### Security design (two coarse levels)
- **Level 1 — node↔node**: one shared **federation token** on every node;
  guards all federation endpoints (work-items, outbox, catalog, health) with a
  single middleware. Delegation only between configured peers.
- **Level 2 — systems using the node**: per-system **client tokens**
  (`api.clients`), individually revocable; guards `submit`/`status`. Default =
  access to all starting agents unless a token lists `agents`. Task results are
  scoped to the owning `client_id`.
- Costs: validators in each client token; optional revocation.
- **Contract** written as `docs/CONTRACTS/LEG-017-security.md`.

# 2026-08-27 — Session 5 (addendum: logging practice)

## Scope
Adopt logging as a standing implementation practice across legio, driven by
the maintainer's observation that a concurrent, decoupled engine must log
everything to be observable at runtime. (Follows Session 5 R-2 contract
implementation; same working session.)

## Work done
- `src/legio/logging.py`: `configure(level, *, root=False, format_string=None)`
  and `get_legio_logger(name)`. legio is a library: modules provision their own
  loggers under the `legio.*` tree and never configure the root logger; the
  helper lets a consumer opt in to verbosity (adding a StreamHandler on the
  `legio` root + setting level, without touching the root logger unless
  requested).
- Module-scoped, structured `key=value` logging added at the lifecycle points of
  a decoupled system:
  - `primitives/beaver.py`: queue push/lease-acquired/contention/idle/ack, board
    set/update (DEBUG/INFO).
  - `agents/tool_agent.py`: run start/task/tool, input ok, schema failure
    (WARNING), result deposited, crash (`logger.exception`).
  - `manager/__init__.py` + `client.py`: submit info, status denied/unknown
    (WARNING), client termination, reaper cancellation.
  - `fed.py`: submit unknown-peer/interface-mismatch (WARNING), deposit (INFO),
    dedup (DEBUG), acceptor-unreachable.
  - `security/middleware.py`: central `authorize` logs every denial once
    (WARNING) by delegating to a pure `_decide`.
  - `tools.py`: register (INFO), unknown-type (WARNING).
  - `patterns/__init__.py`: pattern loaded (INFO).
  - `naming.py`: rejected identifiers (WARNING).
- `tests/test_legio_logging.py` (4): logger nesting, handler attachment,
  root untouched by default, module loggers present.

## Tests run
- `uv run pytest tests/ -q` → **94 passed** (was 90; +4 logging tests).
- `uv run ruff check src/ tests/` → all passed.
- `uv run ruff format --check src/ tests/` → all formatted.
- `uv run pyright src/` → 0 errors.

## Decisions taken
- **Logging is a per-module, per-logger capability** (rule 7 domain-free: only
  messages about agents/tasks/peers/tools/steps, never consumer domain data).
- **legio never configures the root logger**; consumers own logging config. The
  `configure` helper is an opt-in convenience for scripts/tests.
- Structured `key=value` in message text (task_id, agent_id, tool, peer, scope)
  rather than JSON to keep zero new dependencies.
