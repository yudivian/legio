# 2026-09-01 — Session 15d: journal-commit discipline (turn discussion serialized)

## Scope (this turn)
The maintainer brought a governance correction, not a code task: I had let
several turns pass without committing the journal, and had misread the journal
rule (AGENTS.md rule 3) as "close every turn by committing the work tree". This
turn realigned that understanding. No code / no final decision was changed this
turn; the existing uncommitted work tree (16 docs files: README, ARCHITECTURE,
14 contracts) stays as-is — it is a decision in progress.

## What the maintainer clarified (decision serialized)
- **Two distinct things persist separately:**
  1. **The journal (mandatory, every turn).** Each turn must serialize *what was
     discussed and decided* into `docs/JOURNALS/` and commit it **within that
     turn**. This journal commit is fixed and non-negotiable — even when no code
     changed, even mid-session. It is the memory of the turn: decisions, open
     questions, what is still in-flight. It must not "look ahead" to describe
     uncommitted future work as done.
  2. **The work tree (not mandatory per turn).** Code/docs touched in a turn are
     not obligated to be committed that same turn, because they may be a decision
     in progress that the next turn will reshape. The work is committed on its
     own, when it becomes final/stable. The only fixed commit is the journal's.
- The existing rule 3 already said, in essence, the same thing ("No turn ends
  until the journal records that turn"); the failure was compliance, not wording.
  The maintainer asked that AGENTS.md wording be widened to state the
  journal-vs-work-tree split explicitly.

## What I did wrong (acceptance)
- Let turns 15/15b/15c pass without their journal commit until much later, then
  committed only the journal (b8b32c1) describing work still uncommitted — the
  journal "looked ahead". Root cause: I read "nothing is committed until the
  journal records the turn" as "the work tree must be committed at turn close".
  That is the opposite of the intended nuance.

## What I did right
- Persisted the day's journal with each earlier session addendum (15/15b/15c).
- Committed the journal of this turn immediately (this entry is the commit).
